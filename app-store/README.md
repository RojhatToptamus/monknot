# Historical Marketing Screenshots

Monknot is distributed directly through GitHub Releases, not through the Mac
App Store. These source captures remain only because they can be reused for
first-party marketing work; they are not consumed by the application build,
DMG packaging, GitHub Actions release workflow, or website build.

- Canvas: 1440 x 900 pixels (Apple-accepted 16:10 Mac screenshot size)
- Format: RGB PNG without transparency
- Source: the approved designer-delivered compositions built from Monknot's real app captures
- Background: the reusable source is preserved at `assets/background.png`
- Processing: the designer PNGs had fully opaque alpha channels; those channels were removed without changing visible pixels
- Collection: five product modes in dark appearance followed by the same five modes in light appearance
