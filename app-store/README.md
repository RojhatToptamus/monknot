# Mac App Store Screenshots

Upload the PNG files in `screenshots/macos/en-US` in filename order.

- Canvas: 1440 x 900 pixels (Apple-accepted 16:10 Mac screenshot size)
- Format: RGB PNG without transparency
- Source: the approved designer-delivered compositions built from Monknot's real app captures
- Background: the reusable source is preserved at `assets/background.png`
- Processing: the designer PNGs had fully opaque alpha channels; those channels were removed for App Store compatibility without changing visible pixels
- Collection: five product modes in dark appearance followed by the same five modes in light appearance

Apple's current Mac screenshot requirements allow one to ten JPEG or PNG images at 1280 x 800, 1440 x 900, 2560 x 1600, or 2880 x 1800 pixels, without alpha channels:

https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/
