Monknot Support

Email support@monknot.app for help, bug reports, or feature requests.

For a bug report, include:

  • Your macOS version
  • Your Monknot version
  • What happened and what you expected
  • Steps that reproduce the problem
  • A screenshot or error message, if relevant

Common problems

A folder no longer opens

Select the folder again in Monknot. If macOS still blocks access, review Monknot under System Settings > Privacy & Security.

PDF text cannot be searched

Text search works with PDFs that contain selectable text. A scanned PDF without selectable text requires OCR before Monknot can search it.

A terminal session does not start

Include the displayed error, command, and terminal configuration in your bug report.
