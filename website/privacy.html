Privacy Policy

Last updated: August 26, 2026

Overview

Monknot edits supported files in folders that you select. The app requires no account and contains no advertising or cross-app tracking.

Files and Documents

Monknot accesses only the files and folders you choose to open.

It reads and writes supported text files and PDFs on your Mac. PDF annotations and exported documents remain in the locations that you choose.

Monknot does not upload file contents to Monknot servers. A storage or synchronization service can transmit files in the folders that it manages.

Local Application Data

Monknot stores the following application data on your Mac:

  • Application, editor, export, and theme settings
  • Saved folders, recent documents, and security-scoped bookmarks
  • Window, tab, view, and workspace state

Monknot does not use this data for advertising or user profiling. To erase it, remove the app and its related application data from macOS.

Writing Assistance

Spelling, grammar, and system inline predictions use macOS language services.

On macOS 26, the optional beta uses Apple’s on-device language model for reviewed sentence repairs and short completions. Monknot creates a new model session for each request and does not send the text to Monknot servers.

Apple Writing Tools are a separate macOS feature. When you invoke them, macOS handles the request under your Apple Intelligence settings and Apple’s privacy terms.

Terminal Sessions

Terminal sessions run locally through zsh. Monknot keeps bounded terminal scrollback in memory while a session exists and does not persist it as application data.

Terminal commands can save history, write files, read environment variables, or connect to external services. Each command or service controls its data.

Network Connections

Editing local files does not require a Monknot account or cloud service.

Network connections can occur during update checks, update downloads, external link requests, HTML previews with remote resources, Apple Writing Tools requests, or terminal commands.

Software Updates

Monknot uses Sparkle for update checks and downloads. The update feed at monknot.app redirects to the latest appcast and download on GitHub Releases.

Sparkle asks before it enables automatic checks. Monknot does not enable Sparkle system profiling, and update requests contain no document, terminal, or workspace contents.

Analytics and Crash Reporting

The macOS app contains no usage analytics, advertising SDKs, or automatic crash reporting.

This website uses Vercel Web Analytics. It records anonymous page-view data such as the page, referrer, approximate location, device type, operating system, and browser.

Vercel Web Analytics uses no cookies and discards its visitor identifier after 24 hours. Read Vercel’s analytics privacy documentation.

Support Communications

A support email can include your address, device details, screenshots, error messages, and any other information that you provide.

Monknot uses this information to respond, investigate the reported problem, and improve the app. Do not include passwords, private keys, access tokens, or other sensitive data.

Data Sharing

Monknot does not sell, rent, or trade personal information.

Vercel processes website analytics, GitHub hosts update files, and email providers process support messages. Their privacy terms apply to that data.

Data Retention

Local application data remains on your Mac until you remove it.

Monknot discards its in-memory terminal scrollback when you remove the terminal session or close the app.

Support email remains only as long as needed to answer requests, maintain support records, resolve recurring problems, and meet legal obligations.

To request removal of information from a support email, contact support@monknot.app.

Children’s Privacy

Monknot does not target children and does not knowingly collect their personal information.

Changes to This Policy

This page will show a new revision date when Monknot’s features or data practices change.
